(RU)
Это игра, в которой вы ловите фигуры, падающие с неба, и складываете их в коричневую прямоугольную корзину. Если вы поймали фигуру, вы получаете очко. Игра написана на Python с использованием библиотеки Pygame. Если вы хотите установить библиотеку Pygame, пожалуйста, введите "pip install pygame" в командной строке. Если это не сработает, пожалуйста, введите "pip install pygame-ce" в командной строке. Это идеальное упражнение для изучения библиотеки Pygame.

Горячие клавиши:
Стрелки влево/вправо или Q/E - Переместить корзины влево/вправо
Esc - Выход из игры
= или + - Увеличить скорость
_ или - - Уменьшить скорость
Пробел - повторить попытку (если проиграли)


(EN)
This is a game where you catch shapes falling from the sky and put them in a brown rectangular basket. If you catch a piece, you get a point. The game is written in Python using the Pygame library. If you want to install the Pygame library, please type "pip install pygame" at the command prompt. If this does not work, please type "pip install pygame-ce" at the command prompt. This is the perfect exercise to explore the Pygame library.

Hotkeys:
Left/Right arrows or Q/E - Move basket left/right
Esc - Exit game
= or + - Increment speed
_ or - - Decrement speed
Space - try again (when you lost)
